# Markdown Viewer 隐私政策

最后更新：2026-09-27

Markdown Viewer（下称"本扩展"）尊重并保护用户隐私。

## 我们收集什么

**不收集任何数据。** 本扩展没有服务器、没有账号体系、没有统计分析，不会向开发者或任何第三方传输您的浏览记录、文档内容或个人信息。

## 数据的处理方式

- **Markdown 文档内容**：仅在本扩展打开的标签页内于本地解析与渲染，不离开您的设备。
- **工作区（本地文件夹）**：文件夹句柄保存在浏览器本地 IndexedDB，仅用于"最近打开"功能；重新打开时需要您再次授权。文档内容不会被上传。
- **显示偏好**（主题、视图模式等）：通过浏览器自带的 `chrome.storage.sync` 保存在您的浏览器（若登录 Google 账号则随浏览器同步），仅本扩展可读取。
- **网络访问**：本扩展自身不发起任何网络请求。

## 权限用途

- `storage`：保存上述显示偏好。
- `scripting` 与主机权限：用于在检测到您打开 Markdown 文件时向该页面注入渲染脚本；对普通网页不注入、不修改、不读取。

## 联系方式

如有隐私相关问题，请通过本仓库的 Issue 联系我们。
