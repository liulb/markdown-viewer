# 设计说明

本页面用来验证工作区内的**跨文件跳转**。

## 实现细节

- 工作区通过 File System Access API 读取本地文件夹，句柄保存在 IndexedDB，下次打开时重新授权
- 相对链接在渲染后统一改写为工作区内跳转，例如[返回首页](index.md)
- 相对图片改写为 blob URL 展示，如 ![小图](assets/flow.svg)

## 已知限制

1. 非图片、非 Markdown 的相对链接（如 `.pdf`）会标记为不可用
2. 单文件模式下相对路径无法解析，建议使用工作区模式
3. 目录扫描跳过 `.git`、`node_modules` 与隐藏目录
