# 示例工作区

这是 Markdown Viewer 内置的示例工作区，用来演示**多文件浏览**能力：

- 左侧文件树可以切换文件
- 相对链接可以直接跳转，例如打开[设计说明](notes.md)或[返回上一级](./notes.md#实现细节)
- 相对路径的图片可以正常显示：

![架构示意图](assets/flow.svg)

## 工作区特性

1. 支持 `.md` / `.markdown` / `.mdown` / `.mkd`
2. 图片文件（png / jpg / svg / webp 等）会作为相对资源被解析
3. 子目录会折叠成可展开的分组

## 架构流程

```mermaid
flowchart TD
    A[选择文件夹] --> B[递归扫描]
    B --> C{找到 .md?}
    C -->|是| D[文件树浏览]
    C -->|否| E[提示为空]
    D --> F[相对链接跳转]
    D --> G[相对图片显示]
```
